# Raft Survival — мод для Minecraft 1.21.11 (Fabric)

Серверный/клиентский мод: готовый лобби-спавн, выбор режима, режим **«Выживание на плоту»**, сессии (соло / кооператив до 4),
сохранение прогресса, акулы и чайки, крафты, а также встроенный «админ-модуль»: ранги/привилегии, таб, RGB-панель и создание карт.

**Ядро: Fabric** (Loader + Fabric API, Yarn-маппинги, Java 21). Bukkit/Paper-плагины на Fabric не запускаются, поэтому
«плагин» (карты, привилегии, таб, RGB-панель) встроен в тот же JAR — отдельная установка не нужна.

## Сборка
```
./scripts/resolve-versions.sh   # подобрать актуальные Yarn/Loader/Fabric API для 1.21.11
gradle build                     # или ./gradlew build
# JAR: build/libs/raftsurvival-1.0.0.jar
```
Либо просто запушьте репозиторий — GitHub Actions (`.github/workflows/build.yml`) соберёт JAR и приложит его артефактом.
Ставить JAR в `mods/` и на сервер, и на клиенты (нужен Fabric API).

## Игровой цикл
1. При входе игрок попадает на пирс-лобби в океанском измерении `raftsurvival:ocean` (плоский океан, создаётся датапаком мода). Открывается меню (компас в слоте 5 / `/raft menu`).
2. «Выживание на плоту» → создать мир: **одиночный** или **кооператив (до 4)** — публичный, закрытый (по приглашению) или с паролем.
3. Мир = стартовый плот 3×3 + 4 острова: лес, шахта, ферма, маяк. Миры разнесены в океане по слотам.
4. Выход/вылет сохраняет инвентарь, позицию, здоровье, жажду и этап; при повторном входе игра продолжается.

### Прохождение (10 этапов, `/raft quests`)
1. Первый улов → 2. Хлам с волн (бочки/обломки) → 3. Расширь плот (15 досок; доски кладутся на воду вплотную к плоту) → 4. Пресная вода (опреснитель) →
5. Вяленая рыба (сушилка) → 6. Земля! (северный остров) → 7. Дерево и камень → 8. Охота на акул (гарпун, 3 зуба) → 9. Сигнал (ракета + маяк) → 10. Спасение (запуск ракеты у маяка).
Акулы появляются чаще с ростом этапа, жажда и голод поддерживают напряжение.

### Крафты
| Предмет | Рецепт |
|---|---|
| Плотовая доска | 2 обломка / любая доска |
| Верёвка | 3 нити |
| Гарпун | кость + 2 палки (по диагонали) |
| Опреснитель | 5 досок + верёвка + миска |
| Сушилка | 3 верёвки + 4 палки |
| Сигнальная ракета | 3 акульих зуба + верёвка + кость |

## Команды
Игроки: `/raft [menu|lobby|leave|quests|list|create solo|create coop <public|private|password <пароль>>|join <id> [пароль]|resume <id>|invite <ник>|kick <ник>|password <пароль>|public|private|manage|delete]`  
Админы: `/rank list|set <ник> <ранг>`, `/raftmap wand|save|load|list|delete|spawn`, `/raftpanel on|off`, `/raftadmin shark|gull|sessions`.

## Привилегии, таб, панель, карты
* `config/raftsurvival/ranks.json` — ранги и права (`*`, `raft.*`, `raft.map`, `raft.rank`, `raft.panel`, `raft.admin`, `raft.kick.any`…). Впишите свой ник в `owners`.
* Таб: префикс ранга (цвет RGB) + анимированная RGB-шапка, подвал с онлайном/TPS/пингом.
* RGB-панель: переливающийся sidebar со статистикой сервера.
* Карты: `/raftmap wand` → выделить область → `/raftmap save <имя>` → `/raftmap spawn <имя>`; при создании мира появится выбор карты. Блок-сущности не сохраняются.

## Модели
Акула и чайка — модели, заданные в коде (`SharkModel`, `GullModel`) с процедурной анимацией (хвост/плавники/крылья), текстуры генерирует `tools/gen_assets.py`.
Чтобы заменить на модели из Blender/Blockbench — экспортируйте в формат Java Block/Item или перенесите кубоиды в `getTexturedModelData()`.
